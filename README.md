# Plumber Demo Page

Simple static landing page. Drop the files at the repository root.

Deploying to Netlify (recommended):
1. Push this repository to GitHub.
2. In Netlify, choose **New site** → **Import from Git** → connect your GitHub repo.
3. For Build settings leave **Build command** blank and set **Publish directory** to `.` (the repo root).
4. Deploy. Netlify will give you a `*.netlify.app` URL.

To use a custom domain: add your domain in Site settings → Domain management, then follow Netlify's DNS instructions (either set Netlify DNS by updating nameservers or add the recommended DNS records with your registrar).
